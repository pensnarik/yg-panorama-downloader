The program must satisfy the following requirements:

1. The file must begin with #!/usr/bin/env python3
2. All functionality must be implemented in classes.
3. For variables, classes, and methods, clear and human-readable, descriptive names must be used. The code must be self-documenting.
4. The code of methods must be written in such a way that the length of a method does not exceed 10 lines (where possible). If it is not possible to make the code shorter, the algorithm or the architecture of the program/class/module must be reconsidered.
5. The code of each method must work at a single level of abstraction.
6. The best known Python development patterns must be used.
7. All dependencies must be defined in requirements.txt so that the program can be run in a virtual environment.
8. Write unit-test from all basic functionality and run them after any code update.
